Privacy Policy

Nest PTAC Monitor is a personal tool used only by its owner.

What it accesses

With the owner's consent, it uses the Google Smart Device Management API (scope sdm.service) to read the owner's own Nest thermostats: device names, temperature, mode and HVAC status.

How data is used and stored

Data is stored only on the owner's own computer and is used only to show the owner the run time and status of their thermostats. It is not sold, shared or transferred to anyone, and it is not used for advertising.

Revoking access

Access can be revoked at any time from your Google Account at myaccount.google.com/permissions.
